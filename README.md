## 📌 Overview

**Python for AI — From Scratch to Master** is a comprehensive, hands-on learning lab and reference guide designed to bridge the gap between Python basics and production-ready AI engineering. 

Whether you are building retrieval-augmented generation (RAG) pipelines, integrating LLM APIs, working with vector embeddings, or optimizing data-intensive numerical workflows, this repository provides clean, production-grade patterns you can apply directly to your projects.

---

## 🛠️ What's Inside (Modules)

The lab is organized into structured pillars covering the complete modern Python and AI development stack:

1. **NumPy & Pandas for AI** — Vectorization, shapes, broadcasting, cosine-similarity math, and efficient DataFrames.
2. **Production Python** — Type hints, Pydantic validation, dataclasses, async I/O, custom exceptions, and structured logging.
3. **Concurrency & Data Pipelines** — Threads vs. processes vs. async models, generators/lazy evaluation, and robust JSON/file I/O.
4. **LLM & API Patterns** — Clean API wrappers, exponential backoff retries, tool use, streaming, token budgeting, embeddings batching, caching, and RAG context assembly.
5. **Capstone Project** — An end-to-end tiny RAG pipeline connecting all concepts into a unified workflow.
